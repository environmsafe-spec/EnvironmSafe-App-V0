EnvironmSafe

Procurement & Financial Management System

What the system does

One screen records every business event — RFQ received, quotation sent, purchase order, supplier bill, customer invoice, payment in or out, expense, salary. Each row carries its procurement phase, case number, party, project, bank account and document reference, so the procurement file and the accounts are built from the same entry.

From that single ledger the system produces customer and supplier statements with opening and closing balances, project profitability, employee and bank ledgers, and a dashboard of revenue, cost, profit, cash, receivables and payables. English and Arabic, five user roles, print-ready reports.

Use it in a browser

The phone app and the website run the same system from the same files. Open the system in this browser — nothing to install, and it keeps working offline once loaded.

Installing it on a phone

  1. Open this page on the Android device and tap Download the APK.
  2. Android will warn that the file can harm your device — that warning appears for every app installed outside the Play Store. Choose Download anyway.
  3. Open the downloaded file. If prompted, allow your browser or file manager to install unknown apps, then return and confirm.
  4. Tap Install, then Open. EnvironmSafe appears in your app drawer.

Where the build comes from

Every APK is compiled by the Android APK workflow in the repository — not on anyone's laptop — so the download always matches the committed source. Pushing to main rebuilds it; publishing a tag attaches the APKs to a release.
